## Legend

| Code | Meaning |
|---|---|
| **MONEY** | Commercial intent. Should be a **service page** under `/services/`, not a blog post. |
| **PILLAR** | Comprehensive hub article. Receives internal links from its spokes. |
| **SPOKE** | Supporting article. Links up to its pillar and across to siblings. |
| **BRAND** | Brand/authority page. Low search volume, high conversion and E-E-A-T value. |
| **PAGE** | Conflicts with an existing Next.js route — upgrade that page, do not create a competing post. |

| Status | Meaning |
|---|---|
| **NEW** | No conflict. Safe to write immediately. |
| **OVERLAP** | Partial overlap with an existing article. Write, but differentiate the angle and cross-link. |
| **DUP** | Near-identical to an existing published article. **Decision required** before writing. |
| **MERGE** | Two entries inside this list of 200 target effectively the same query. **Decision required.** |

### 2. Roughly seventeen internal merge pairs

Entries inside the 200 that target effectively the same SERP: A16/A7, A23/A30, A27/A1, A34/A9, A35/A8, B3/B1, B29/B28, B30/B28, C3/C1, C14/E20, C22/C13, C23/A30, D16/D2, D23/G2, E6/E5, E11/E10, F2/F8/F9/F10, F6/F5, F18/F16, G4/C12, G5/G14, H14/C30, H15/C18.
**Recommendation:** write one strong page each and treat the sibling as a section within it. Publishing near-identical pages is how sites acquire keyword cannibalisation at scale.

### 3. Three city entries conflict with existing routes

D3 (Lahore), D6 (Islamabad), D8 (Karachi) already exist as Next.js pages. Writing blog posts for the same keywords would compete with your own landing pages.
**Recommendation:** upgrade the existing routes. Build **new** routes for Faisalabad (D4), Sahiwal (D5), Rawalpindi (D7).

### 4. "Best [X] in Pakistan" titles vs your own brand rule

Roughly 12 entries are phrased as "Best …". Your standing instruction is never to claim BITSOL is number one or the best unless independently verified.
**How I will handle it:** these pages get written as genuine buyer's-guide/selection-criteria content — what to evaluate, what questions to ask, how pricing works, red flags — with BITSOL positioned on capability and process, not on a self-awarded ranking. This satisfies the keyword, respects the rule, and matches what actually ranks for "best" queries.

### 5. MONEY entries belong on service pages, not the blog

About 55 of the 200 are commercial-intent queries. Your own Phase 1 says build the money pages first. These should live under `/services/<slug>` with the blog spokes linking up into them.
**Recommendation:** treat them as page copy, delivered in the same markdown format, and route them to `/services/` when you publish.
